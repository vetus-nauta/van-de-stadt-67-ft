# Репозиторий и выдача

Канонический репозиторий: `vetus-nauta/van-de-stadt-67-ft`, ветка `main`. Написание `van-der-stadt-67-ft` в поручении сопоставлено с найденным существующим репозиторием; переименования не было. Локальная копия: `/home/alexey/Groot/van-de-stadt-67-ft`.

Существующие `docs/`, `sources/SOURCES.md`, `data/spec-matrix.csv` и технический `HANDOFF.md` сохраняются. Новые правила — `office/`; рабочие операционные реестры — `data/office/`; шаблоны — `templates/`; навыки — `skills/`; инструменты — `tools/`. Ввод новых технических документов не меняет старые незаметно.

Перед изменением проверить git status, получить remote, прочитать затронутые инструкции. Не затирать чужие изменения. Внести согласованные правки, `office/CHANGELOG.md`, проверить ссылки, реестры и применимые тесты. Публиковать только относящиеся к задаче файлы, без force push. После публикации получить удалённый commit и проверить совпадение дерева/байтов. До проверки удалённого сохранения сообщать только локальное состояние.

Репозиторий публичный. Операционные инструкции разрешены текущим поручением. Частные предложения, персональные контакты, платёжные сведения и закрытые чертежи не становятся публичными автоматически. При отсутствии права публикации хранить их локально в `.local/` либо в согласованном закрытом хранилище; в публичном реестре оставить безопасный ID и статус доступности. Никаких токенов, паролей и лицензий.

Выдача по задаче: `deliverables/<task-id>/<version>/00_<основной-файл>` и `01_support/` для сопровождения. Основной файл — первым отдельной ссылкой, папка — следующей. Название и формат задаются получателем; XML не является обязательным форматом яхтенной сметы. Для непубличных результатов применяется такая же структура внутри `.local/deliverables/`.

Версии v001, v002 и далее не перезаписываются после выпуска. В сопровождении: исходная база/ревизия, расчёт, проверка, решение, открытые вопросы и manifest. Историю изменений держать компактно. Общую базу сметчика не изменять только потому, что изменилось правило этой яхты; перенос обратных уроков делать отдельно с обоснованием.
