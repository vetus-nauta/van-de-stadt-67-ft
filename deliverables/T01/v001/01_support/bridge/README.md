# Rhino → Blender: рабочая визуальная подоснова

Дата: 10.09.2026. [Готовая сцена Blender](vds67-reference.blend), [OBJ для обмена](vds67-reference.obj), [метаданные](metadata.json), [проверка импорта и повторного открытия](blender-verification.json).

В Blender 4.0.2 импортированы восемь отдельных mesh-объектов: две оболочки корпуса #133/#144, кандидат палубы #478 и кандидаты крыши #198/#333–336. Имена и свойства объектов сохраняют UUID оригинала. Всего 5444 вершины и 7941 грань. Выбраны исходные cached render meshes из `2-1.3dm`; поверхности не перестраивались, вершины не сваривались, отверстия не закрывались.

Единица сцены — метр. Матрица `rhino_native_to_working` выпуска G02 сначала переводит исходные миллиметры в рабочие миллиметры, затем координаты делятся на 1000. Ориентация XYZ сохранена. Z=0 — чертёжный репер возле надписи CWL1250, не утверждённая ватерлиния. Матрица, обратное преобразование и SHA исходника, G02 и экспортера находятся в метаданных. DWG через эту операцию не переносится; ограничения его согласования с Rhino сохраняются.

Подоснова подходит для осмотра, размещения новых концептуальных объектов и иллюстраций. Она не является точной NURBS/STEP-моделью, замкнутым корпусом для гидростатики, обмерной моделью или производственным чертежом. Точность исходной тесселяции неизвестна. Полный набор, интерьер и предлагаемые переделки в сцену не добавлены. Существующую подоснову следует сохранять отдельно от создаваемых проектных объектов.

Открытие: Blender → File → Open → `vds67-reference.blend`; клавиша Home в 3D-виде показывает все объекты. В Outliner можно по отдельности скрывать `roof_*`, `deck_*`, `shell_*`. Свойства источников доступны в Custom Properties, полный паспорт — в текстовом блоке `READ_ME_REFERENCE_LIMITS`. Новые варианты сохранять под новым именем, исходную сцену выпуска не перезаписывать.

Воспроизведение из корня репозитория, где `OUT` — новый, ещё не существующий каталог:

```bash
OUT=.local/T01/bridge-reproduction
.local/cad-tools/rhino/venv/bin/python tools/cad/rhino_cached_mesh_to_obj.py --out-dir "$OUT"
blender --background --python tools/cad/blender_reference_scene.py -- --bridge-dir "$OUT"
```

Экспорт требует уже имеющуюся библиотеку rhino3dm 8.32.1. Скрипты отказываются перезаписывать результаты. Blender импортирует OBJ с явными осями `forward_axis=Y`, `up_axis=Z`; сохранение и повторное открытие проверены по всем восьми UUID, количеству вершин/граней и границам каждого объекта. Допуск проверки переноса координат — 0.00001 м; это технический допуск сравнения чисел, не заявленная точность модели. SHA бинарного `.blend` относится к конкретному выпуску; его побайтовая воспроизводимость не заявлена. Независимую проверку оформляет отдельный проверяющий в общей папке T01.
