# Linux-инструменты T01 — установка начальником

10.09.2026. Прямое поручение владельца: «добивай инструменты». Linux Mint 22.3 / Ubuntu noble.

Установлены из настроенного системного репозитория командой `sudo -n apt-get install -y blender inkscape`: Blender 4.0.2 и Inkscape 1.2.2, 79 новых пакетов с зависимостями, около 549 MB установленного объёма. Удалений и обновления остальных пакетов не выполнялось. Это версии дистрибутива, не заявление о последних upstream-выпусках. `dpkg --audit` после установки не выдал замечаний.

Blender запущен графически с `--factory-startup`, окно обнаружено по PID. Inkscape экспортировал исходную схему `deliverables/G02/v001/01_support/layout/option-B.svg` в отдельный локальный PDF; `pdfinfo` подтвердил одну страницу. Оригинальный SVG не менялся. Логи и временный PDF: `.local/tooling/`. Путь с ошибочным флагом `--new-window` был отклонён Inkscape; повтор запуска выполнен без этого флага, окно открыто. Графический запуск ODA также проверен. Итоги — [gui-check.json](gui-check.json), экспорт — [inkscape-check.log](inkscape-check.log).

Системные ярлыки Blender/Inkscape установлены пакетами. Для ранее подготовленного ODA создан пользовательский ярлык `~/.local/share/applications/vds67-oda-converter.desktop`, запускающий task-local бинарь ODA 27.1. Привязки файлов по умолчанию не менялись. FreeCAD устанавливается отдельным специалистом из официального AppImage; его точная версия и проверка — в отдельном протоколе.

Назначение инструментов: [FreeCAD](https://www.freecad.org/features.php?lang=us) — параметрические детали и обмен STEP/IGES; [Blender](https://www.blender.org/features/modeling/) — пространственное моделирование и визуальная компоновка. Нативный точный импорт нашего Rhino в FreeCAD пока не доказан. Сеточный мост в Blender сохраняет только проверяемую выборку cached mesh, не NURBS и не производственную геометрию.
