# T01 — рабочие инструменты Linux для VDS67

10.09.2026. По поручению владельца дополнен комплект для проектирования, визуальной компоновки и оформления. [Папка сопровождения](01_support/).

| Инструмент | Назначение и границы |
|---|---|
| FreeCAD 1.1.3 | Параметрические детали и сборка проектной геометрии, FCStd и обмен STEP. Точный импорт существующего Rhino ещё не подтверждён |
| Blender 4.0.2 | Визуальная 3D-компоновка, новые концептуальные объекты и интерьер; подготовлена открываемая подоснова нашей яхты |
| Inkscape 1.2.2 | Оформление SVG, аннотации и выпуск PDF. Экспорт схемы G02 проверен |
| LibreCAD 2.2 | Уже установленный 2D-редактор DXF |
| ODA File Converter 27.1 | Уже подготовленный конвертер DWG/DXF; добавлен ярлык меню, графический запуск проверен |
| rhino3dm / ezdxf / LibreDWG | Существующие программные средства извлечения, проверки и преобразования геометрии |
| PDF-просмотрщик / Poppler | Существующие средства чтения листов и извлечения изображений/текста |

Запуск графических программ — через меню Linux по названию. Blender и Inkscape установлены из репозитория дистрибутива, FreeCAD — отдельным официальным AppImage. Установочные файлы и среды остаются локальными, в GitHub сохраняются инструкции, результаты проверки и производные проектные файлы.

FreeCAD проверен на отдельной тестовой детали с отверстием: сохранение и повторное чтение FCStd/STEP дали валидное тело и совпадающий объём. Это проверка работоспособности, не расчёт конструкции яхты. Запуск из терминала: `~/.local/bin/freecad`.

## Открыть яхту в 3D

[Готовая сцена Blender](01_support/bridge/vds67-reference.blend). В Blender: File → Open, выбрать этот файл; Home в 3D-виде показывает все объекты. В дереве объектов можно скрывать крышу, палубу и половины оболочки. Новую работу сохранять под новым именем.

Это восемь раздельных mesh-объектов из исходного Rhino: две оболочки, палуба и пять поверхностей крыши. UUID сохранены, единицы сцены — метры, координаты — рабочая система G02. Проверены импорт, сохранение и повторное открытие. [OBJ, паспорт и команды повторения](01_support/bridge/README.md).

Сеточная подоснова даёт возможность осматривать яхту и размещать концептуальные объекты. Она не заменяет точные поверхности, чистые внутренние габариты или замкнутую гидростатическую модель. Переход Rhino → точный CAD остаётся отдельной технической задачей. Крыша, кормовой гараж и другие будущие изменения в этой сцене ещё не спроектированы.
