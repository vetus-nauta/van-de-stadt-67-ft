# EXP-002 — корректировка формы надстройки

10.09.2026. Прямое уточнение владельца после просмотра EXP-001.

| Поручение | Принятая для эскиза интерпретация | Проверка |
|---|---|---|
| Крышу оставить по размерам | Сохранить верхнюю крышу EXP-001, её продольный контур, ширину и ступень; не тянуть высокую часть до носа | Сравнить геометрию наследуемой крыши |
| Низ растянуть к палубе | Наклонные боковины с более широким основанием, классическая яхтенная надстройка | Основание шире верхнего контура там, где допускает палуба; не закрывать проходы |
| До половины поднять палубу по переднему краю | Поднять непрозрачную нижнюю часть лба примерно на половину прежней высоты лобового остекления | Показать меньшую высоту окон; это внешний комингс/надстройка, не подтверждённый подъём внутреннего пола |
| Ещё 3 м вперёд приподнятой крыши с остеклением | Низкое ступенчатое продолжение от X−7.798 до X−4.798, а не ещё 3 м высокой рубки | Размерная линия и отдельные высотные параметры |
| По бокам протопчины | Сохранить проходы между новой надстройкой и кромками исходной палубы | Измерить плановые зазоры, отличать их от чистой полезной ширины с учётом комингсов/стоек |
| Впереди форпик и якорное хозяйство | Перед низкой надстройкой показать отдельные резервы люка форпика, якорного колодца и лебёдки | Не выдавать наружные резервы за доказанные внутренние отсеки или выбранное оборудование |
| Хардтоп над кокпитом | Отдельная крыша над существующим кокпитом, открытая по бокам | Плановое покрытие, опоры, конфликты доступа и будущая проверка рангоута |

Первый эксперимент остаётся отдельной неизменённой версией. Новые геометрические размеры, кроме прямо заданных 3 м, являются предложениями. Координаты мачты и чистого пола, прочность, масса, остойчивость и совместимость с парусами пока не подтверждены. Два метра роста нельзя объявлять обеспеченными во всей надстройке только по внешнему силуэту.
