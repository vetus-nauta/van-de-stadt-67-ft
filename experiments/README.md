# Эксперименты с яхтой VDS67

Здесь хранятся отдельные варианты переделок. Они не заменяют исходные чертежи или утверждённый проект. Каждый эксперимент имеет свой номер, параметры, источник геометрии, изображения и границы проверки. Для новой итерации после выпуска создавать новую версию/номер, исходные данные не перезаписывать.

- [EXP-001 — продление и подъём рубки](EXP-001/00_proposal.md): первый эскиз по поручению владельца 10.09.2026.

`documentation/` и прежние `deliverables/` сохраняются без изменений. В экспериментальной сцене исходная геометрия отделена от новых объектов; скрытие элементов для показа варианта не означает удаления из оригинала.

- [EXP-002 — классическая надстройка и хардтоп](EXP-002/00_proposal.md): корректировка наклона бортов, ещё 3 м низкого носового продолжения, проходы и крыша кокпита.

- [EXP-003 — фальшборт и плавные сопряжения](EXP-003/00_proposal.md): отдельная доработка по подтверждённому владельцем замыслу EXP-002.
