# G03 — численная геометрическая основа МО и прохода

Статус: **предварительная геометрия, не обмер и не рабочий проект**. Проверка 18 сечений и двух полных площадок по сетке обнаружила конфликты предложенных настилов с оболочкой. Они раскрыты ниже для дальнейшего изменения компоновки.

## Система координат

G02 working и EXP003 world совпадают: метры=(Rhino native mm+[1294.16,19381.843773828055,24837.674386867988])/1000. X растёт к носу, Y поперёк, Z вверх. X=0 — передний конец вспомогательной линии234, не форштевень; Z=0 — геометрический датум, не подтверждённая ватерлиния. Поэтому центрально-кормовой участок — отрицательныеX, а не +5…+10м. ПровереныX−15…−9.5, включая точные границы новой гипотезы−14.87…−11.27.

Исходные314 объектов сохранены в EXP003. Ширины получены лучами по оболочкам133/144; палубные кромки — пересечением семплированных исходных кривых478 изG02. Интерполяция и cached meshes не дают точности заводскогоBrep. Шесть знаков JSON — вычислительный след, не миллиметровая точность построенного корпуса. Пустое пересечение у оси может быть швом сеток и не означает отсутствия днища.

## Проверка предложенных настилов

Кандидат: внешнееМОX−14.87…−11.27,Y±1.30; внутренний полY±1.20. ПроходY−2.05…−1.30 шириной0.75. Под настилами принят **условный вертикальный резерв0.15м** для набора и конструкции пола. Проверена сетка с шагомX0.10/Y0.05 по всей каждой площадке; это не непрерывный анализ поверхности.

- ER: 1778 пересечений. Худшая точка оболочкиX-14.870,Y-1.200,Z-0.769705. При настилеZ-0.70 остаётся0.070м. Для резерва0.15 нужен постоянный настил не нижеZ-0.620.
- passage: 592 пересечений. Худшая точка оболочкиX-14.870,Y-2.050,Z-0.336601. При настилеZ-0.35 остаётся-0.013м. Для резерва0.15 нужен постоянный настил не нижеZ-0.187.

Предварительный полМО−0.70 не проходит резерв150мм; возможное исправление — поднять до−0.60, сохранив ширину, либо сузить низкую часть. Предложенный верхний пол салонаZ1.10 при общей глубине его структуры/обшивки0.18 даёт потолокМОZ0.92. ВысотаМО тогда1.52м при полу−0.60; прежние1.62м при−0.70 пока не обеспечены. У верхнего салона высота до консервативного низа крыши3.125 составляет2.025м; дополнительные финишные слои уменьшают её.

На кормовом наружном крае прохода настил−0.35 и−0.40 конфликтуют уже с оболочкой. Поднятие прохода примерно до−0.18 помогает нижнему габариту, но под передним участком палубы даёт только1.686м чисто при вычете0.18 на потолочный набор/обшивку. **Это не проход для человека2м.** Нужна другая геометрия: смещение внутрь с изменением шириныМО, локальные ступени/понижение с проверкой оболочки либо изменение верхнего ограждения/палубы. Проём в верхнем салонном полу над проходом должен быть явным и уменьшает площадь/ширину салона. Отверстие само по себе не устраняет боковую палубу впереди.

Припуски0.10/0.15/0.18м — проектные сценарии, не рассчитанные сечения. Обмер, фактический набор, изоляция, покрытия, крепления оборудования и прочность нового перекрытия остаются неизвестны. Таблица даёт численную основу для следующей модели, не утверждённую помещаемость.

## Воспроизведение и сохранность

`blender -b --python deliverables/G03/v001/01_support/extract_geometry.py` читает EXP003 иG02, пишет только geometry-basis.json вG03. Сцену не сохраняет, CAD/DWG/3DM/PDF не изменяет. SHA входов записаны вJSON. Генератор повторно пишет собственныйJSON; финальный выпуск для воспроизведения копировать в отдельный рабочий checkout.
