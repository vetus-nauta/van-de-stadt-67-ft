# G01 · Независимая проверка

10.09.2026 · Проверяющий `/root/geometry_review`, не автор Rhino/DWG/Survey. **REVIEWED_FOR_ANALYTICAL_SCOPE.** Главный документ и три профильных результата проверены. Рекомендован внутренний выпуск G01 только в области разбора исходников, производных изображений и плана обмеров; окончательное принятие выполняет начальник. Полная размерная модель и пригодность для изготовления не приняты.

## Воспроизведённые проверки

[Собственный скрипт](check_geometry.py) заново читает оригинал 3DM; авторский анализатор не импортирует и не запускает. [Результаты](independent-results.json) фиксируют SHA-256 всех 7 файлов реестра DOC-001–006/AUX-001: совпадают с исходной описью. Проверены архив Rhino 3, единицы mm, настройка абсолютного допуска 0,01, 491 объект, 8 слоёв (420 HULL, 71 MD_RAILS), распределение типов, все UUID, 314 Brep/516 граней/516 сохранённых render meshes, 6 solid. `IsValid` всех 491 объектов — свойство чтения модели, не одобрение конструкции.

Отдельная выборка 513 точек параметра каждой кромки против 129 у автора повторяет охват пары #133/#144: 20290,822 × 5755,389 × 3289,737 мм. Округление автора 20,291 × 5,755 × 3,290 м подтверждается **только для этого метода и этих UUID**. Точность экстремумов поверхностей не доказана. Сохранённые сеточные bounds выбранных объектов совпали с автором без разницы. Дополнительно проверены выбранные объекты крыши, палубы, локальных внутренних поверхностей и линия #234; координаты сохранены в JSON. Автор явно разделяет API bbox, edge samples и cached meshes, не называет охват размером яхты.

Прочитаны Rhino и Survey отчёты, 14 строк обмера; просмотрены контрольные изображения исходных GA/Sailplan и проекция HULL. На GA подтверждаются ориентация носа вниз, центральная машинная зона под поднятым салоном, кормовая спальная зона и контур лодки на продольном разрезе. Содержимое CAD/PDF отделено от состояния построенного корпуса. FC-01–04 не превращены в утверждённый проект: объект удлинения, типоразмер тендера, борт и траектория загрузки остаются открытыми.

## Независимая сверка DWG → JSON/DXF

[Собственный скрипт DWG](check_dwg.py) сопоставил [raw JSON и DXF](independent-dwg-results.json) без запуска авторского анализатора. Исходная сигнатура AC1018; в decoded JSON 6918 записей OBJECTS. Все 1241 объекта modelspace DXF имеют соответствующие handles в JSON, типы согласуются: 814 LINE, 188 TEXT, 107 ARC, 91 LWPOLYLINE, 27 POLYLINE_3D, 3 POLYLINE_2D, 11 INSERT. Проверены все концы 814 LINE и вершины всех 27 3D-полилиний: максимальное расхождение 5,46·10⁻¹² координатной единицы. Все 188 текстов совпали. Это сопоставление двух производных одного декодирования, не доказательство полноты оригинала.

В обоих представлениях INSUNITS=0, LUNITS=2, DIMSCALE=10, DIMLFAC=1. Настройка не задаёт физическую единицу. Текст FULL SIZE FRAME PATTERNS, 430-2-0, 7-6-'96, 1:1 действительно присутствует в decoded JSON (первая группа handles 7D16–7D1C); это исторические надписи, не назначение масштаба натурного корпуса. Отдельный audit свежего DXF подтвердил два исправления code103: удаление INSERT#4C21/#4C22 из-за отсутствующего определения BLOCK. Предупреждения CRC и служебных секций прочитаны в логе конвертера. Они ограничивают полноту чтения; повреждение оригинала ими не установлено.

Для повторения без перезаписи выпуска:

```sh
.local/cad-tools/dwg/venv/bin/python deliverables/G01/v001/01_support/review/check_dwg.py --out-dir .local/G01/review/recheck
```

## Граница независимости

Проверяющий использует отдельный код, но ту же библиотеку rhino3dm, что автор. Ошибка общего CAD-движка этим не исключена. Просмотрены рендеры исходных PDF, созданные другим агентом; их геометрическое измерение не выполнялось. Полная поверхностная топология, зазоры/пересечения, гидростатика, массы, прочность и натурная идентичность не проверялись. Обмерный план принят только как адресное задание, все 14 записей PLANNED_NOT_MEASURED. Изображения и координаты не дают права на изготовление.

Команда воспроизведения из корня репозитория:

```sh
.local/cad-tools/rhino/venv/bin/python deliverables/G01/v001/01_support/review/check_geometry.py --out-dir .local/G01/review/recheck
```

Rhino distribution 8.32.1 / runtime `__version__` 8.32.2 — известное расхождение маркировки, явно раскрытое автором. Это не два независимых движка. [Реестр замечаний](findings.csv) закрыт для аналитической выдачи; G01-R06 сохраняется как существенное ограничение следующей стадии.

Устойчивые ID проверки Rhino относятся к 491 **ObjectID**. UUID восьми слоёв могут меняться при повторном чтении старого архива этим parser; ссылки на слои выполняются по index+name, а не по LayerID. Этот предел обнаружен и проверен при повторном запуске автора; независимый скрипт на LayerID не опирается.

Численная привязка DWG ±2879,46 проверена отдельно по координатам вершин POLYLINE #7A76 (37 вершин) и #7A9D (22 вершины), слой 7: min X = −2879,45972; max X = 2879,45972; охват 5758,91944 единицы. Первоначальная ссылка на неназванные «отдельные кривые» исправлена автором на эти handles и метод. Классификация как палубной кромки остаётся интерпретацией; ширина яхты этим не установлена. Ортогональные DWG-проекции просмотрены: оси/родные единицы/исключения явно подписаны.

## Финальное чтение и решение проверяющего

[Главный документ G01](../../00_geometry-review.md) прочитан после завершения авторских разделов. Он точно передаёт результаты, не объединяет несогласованные оси/редакции, не назначает натурных размеров, удлинения корпуса или тендера и раскрывает DWG-неполноту. Замечание G01-R08 по прослеживаемости координат исправлено и повторно проверено. Открытых ошибок, препятствующих **ограниченному аналитическому выпуску**, не найдено. G01-R06 не закрывается как техническая проблема: требуется независимое CAD-чтение и восстановление/проверка отсутствующих зависимостей перед размерным применением.

[Точные хеши проверенных результатов](checked-inputs.json) фиксируют состав чтения. Manifest всего выпуска и синхронизацию GitHub оформляет начальник после этого протокола. При изменении существенных координат, выводов или ограничений зависимая часть подлежит повторной проверке.
