# Проверка прайсов комплектного Yanmar 8LV320

Дата доступа: 11.09.2026. Область: датировка прайса Klomp и поиск альтернативного публичного прайса. Это отдельная проверка источников; M03 не изменён.

**Результат:** цену Klomp 37 800 EUR без BTW нельзя использовать как подтверждённую актуальную цену 2026 года. Действительная дата выпуска прайса не установлена. Пометка поисковика «9 месяцев» не является датой документа. Прямое получение PDF сейчас возвращает 404; извлечь его metadata и сохранить сам файл не удалось. Нельзя честно присвоить ему дату, SHA или статус скачанного оригинала.

## Klomp

[Исходный URL PDF](https://www.klompscheepstechniek.nl/images/downloads/Yanmar-pleziervaart-prijslijst-losse-pagina.pdf). При первом открытии web показал индексированный шестистраничный документ, страница 3: 8LV320, KMH50A, VCS, кабель 5 м, 12 В / 180 А, масса с редуктором 509 кг, 37 800 EUR без BTW. Это комплект с редуктором и указанным управлением, а не цена голого двигателя. Полный монтажный состав этим не доказан.

Повторный web-open дал HTTP 404; прямые HTTPS с www, HTTPS без www и HTTP также дали 404. Главная страница сайта показывала Website Startup. Screenshot последней страницы не получен. Из индексированного текста видны обозначения старой VCS и ссылки на RCD2 с датой 18.01.2016: последняя — дата упомянутого требования, **не дата прайса**. Признаки старой комплектации не позволяют назначить точный год. Статус: `INDEXED_NET_UNDATED_ORIGINAL_UNAVAILABLE`, в текущую КАЦ не допускается как актуальное предложение.

## Локальное свидетельство и SHA

Ни один из проверяемых PDF не получен как валидный файл `%PDF`; отсутствующий PDF не заменялся HTML-ошибкой. Журнал статусов и HTTP-заголовков сохранён локально: `.local/M04/download-log.json`.

SHA-256 журнала: `c677b0b0adde960d2ddc95102e489d5f1880b91797505d42a091813edd5ef262`.

SHA оригинального Klomp PDF: **не установлен — файл недоступен**. Полные сторонние документы в выпуск не добавлялись. Для денежного сравнения нужен доступный актуальный прайс либо живая карточка/КП с точным комплектом и явным NET; дата просмотра должна оставаться отдельной от даты цены.
