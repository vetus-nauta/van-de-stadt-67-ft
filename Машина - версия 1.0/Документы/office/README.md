# Операционный офис

Стартовая версия 1.0, 10.09.2026. Офис организован для управления проектными исходниками, сметами, закупочными сравнениями и изменениями. Морская специализация предстоит назначенной команде.

**Начальнику начать с [хендофа](HANDOFF-TO-HEAD.md).**

| Задача | Рабочий документ |
|---|---|
| Полномочия и границы | [Устав](charter.md), [паспорт](project.json) |
| Назначить исполнителей и передать работу | [Роли и передачи](roles-and-handoffs.md), [шаблоны](../templates/README.md) |
| Пройти от исходника до выпуска | [Порядок работы](workflow.md) |
| Сформировать стоимость и сравнить КП | [Правила оценки](cost-policy.md) |
| Проверить источники и управлять изменениями | [Доказательства и изменения](evidence-and-changes.md) |
| Принять результат | [Контроль качества](quality-and-release.md) |
| Вести реестры | [Словарь данных](data-dictionary.md), `data/office/` |
| Подготовить специалистов | [План специализации](specialization-plan.md), [навыки](../skills/README.md) |
| Проверить арифметику и различия | [Инструменты](../tools/README.md) |
| Зафиксировать новую версию | [Репозиторий и выпуск](repository.md), [история](CHANGELOG.md) |

Готовность запуска: операционные правила и реестры созданы. Готовность сметы: исходные объёмы, цены, базовая валюта и утверждённый состав достройки ещё не установлены. Пустые денежные реестры не означают нулевую стоимость.

Во время подготовки поступила [концепция премиального оснащения](../docs/16-premium-builder-specification.md). Её предварительные цели учитываются отдельной задачей T11; 73 строки старой технической матрицы не объявлены полным охватом этой новой спецификации.
