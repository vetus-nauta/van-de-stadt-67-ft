# Решение о выпуске

- Проект / задача / версия / дата:
- Вид результата: исследование / рабочая смета / базовый бюджет / закупочный пакет:
- Получатель и назначение:
- Основание полномочий выпускающего:
- Основной файл, приложения и SHA-256 каждого:
- Проверка и закрытие замечаний:
- Включённый состав и явные исключения:
- Открытые вопросы и согласованные ограничения:
- Внутреннее решение начальника:
- Требуемые внешние/владельческие согласования и их фактическое состояние:
- Разрешение закупки: отдельное основание либо НЕ ВЫДАНО:
- Путь выдачи и опись:
- GitHub: разрешённый состав, commit, результат сверки либо только локальное хранение:

Не заполнять утверждение или подпись за другого участника. После решения изменение байтов требует новой версии.
