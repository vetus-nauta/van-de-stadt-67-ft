# Рабочие шаблоны

Копируй нужный документ в рабочую папку конкретной задачи. Заполняй реальные значения; пустое поле — не согласование.

- [Задание](task.md) — до поручения исполнителю.
- [Хендоф](handoff.md) — при каждой передаче.
- [Решение по пробелу/варианту](decision.md) — до зависимой подстановки.
- [Проверка](review.md) — независимая приёмка.
- [Решение о выпуске](release.md) — точный комплект и ограничения.
- `registers/` — пустые CSV-формы; заполненные активные реестры находятся в `data/office/`.

Поля и связи описаны в [словаре](../office/data-dictionary.md). Шаблоны не содержат производственных цен, утверждений или фиктивных предложений.

- [U01 — пустой шаблон будущей УТВ яхты (XLSX)](../deliverables/U01/v001/00_UTV_template.xlsx) · [инструкция](../deliverables/U01/v001/01_support/00_readme.md). Для заполнения создавать отдельную рабочую копию.
