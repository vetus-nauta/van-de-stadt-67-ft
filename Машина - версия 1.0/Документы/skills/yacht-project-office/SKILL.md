# yacht-project-office

Начни с [хендофа начальнику](../../office/HANDOFF-TO-HEAD.md) и `office/project.json` от корня репозитория. Устанавливай конкретный вид результата и границу работ до назначения расчётов.

Назначай ограниченные задачи по [ролям](../../office/roles-and-handoffs.md), фиксируй входы, продукт и критерий завершения. Специализация команды выполняется отдельно по [плану](../../office/specialization-plan.md); не заявляй освоение по факту создания роли. Не запускай всю программу старого технического HANDOFF без текущего поручения.

При недостаточных данных сначала предложи источник, способ закрытия и влияние; применяй уже полученные решения в их области. Перед выпуском — независимая проверка существенного расчёта, точная версия и решение. Бюджет не разрешает закупку автоматически. Правила и уроки фиксируй в этом репозитории; основной результат выдавай первым отдельным файлом.
