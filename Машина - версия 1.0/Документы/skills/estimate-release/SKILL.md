# estimate-release

Прочитай [порядок выпуска](../../office/repository.md). Принимай точный основной файл, сопровождение, протокол и решение по версии. Наличие manifest не утверждает расчёт.

Проверь, что файлы открываются, выводы согласованы, приложения доступны и ограничения видны. Для форматов со схемой или целевым ПО фиксируй отдельный результат проверки; не объявляй импорт выполненным по синтаксическому разбору.

Новая правка после выпуска — новая версия. Основной нужный файл первым отдельно, сопровождение одной папкой. В публичный GitHub публикуй только разрешённый состав; локальный commit не доказывает удалённую запись. После публикации сверяй удалённый SHA и байты; сохраняй подтверждение вне утверждённого неизменяемого пакета.
