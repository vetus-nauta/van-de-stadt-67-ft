# Базовые навыки команды

Эталон находится в этом репозитории. Навыки используют соседние `office/`, `templates/` и `tools/`; переносить вместе с этими разделами. Сейчас они доступны по прямому пути; глобальная установка на компьютер не требуется для хендофа.

- [yacht-project-office](yacht-project-office/SKILL.md) — Руководство проектно-сметным офисом Van de Stadt 67 ft: задания, приём результатов и подготовка отраслевой команды.
- [estimate-evidence](estimate-evidence/SKILL.md) — Прослеживаемое извлечение исходных данных и количеств для проектной сметы; применяй при приёме спецификаций, чертежей и КП.
- [estimate-costing](estimate-costing/SKILL.md) — Сопоставление коммерческих предложений и воспроизводимый расчёт стоимости проекта без автоматического назначения отраслевых ставок.
- [estimate-change-review](estimate-change-review/SKILL.md) — Независимая проверка смет и анализ изменений по устойчивым ID, объёмам, ценам и составу.
- [estimate-release](estimate-release/SKILL.md) — Комплектование и версионный выпуск проверенных проектно-сметных документов с описью и хешами.

Будущий начальник передаёт специалисту нужный навык с ограниченной практической задачей и проверкой. Узкие отраслевые знания добавляются после работы с первичными источниками и проверки применимости.
