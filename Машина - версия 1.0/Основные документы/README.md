# Основные документы машинного отделения

1. **01 — Смета машинного отделения.xlsx** — текущая рабочая смета M07, налоговые колонки внутри.
2. **02 — Смета для печати.pdf** — печатная версия той же сметы.
3. **03 — КАЦ оборудования.xlsx** — сравнение вариантов оборудования M03.
4. **04 — Цены и предложения из открытых источников.xlsx** — исследование цен M02, ссылки и основания.

Это точные копии соответствующих выпусков. Полная смета ещё не закрыта: позиции без цен отмечены в книге. Индивидуальные КП поставщиков пока не получены; опубликованные цены и каталоги служат основанием рабочей КАЦ.
